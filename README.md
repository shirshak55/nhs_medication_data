# NHS Medication Data

This script will scrape data from NHS website and create structured data.

## Quick start

- Install: `bun install`
- Browser: `bunx playwright install chromium`
- Run: `bun start`

## Dev

- Format: `bun run fmt`
- Build native: `bun run build:exe`

## Output

- Generates `output.json` in the project root.

## Features

- Parallel tabs
- Native executables
- Clean configs, logging, Zod validation
